Paper, tuned tighter.

Origami keeps the whole Paper API and every optimisation you rely on, then adds the patches and knobs that squeeze more out of a busy server.

Faster where it counts

Async chunk generation and I/O, distance-aware entity ticking, and batched hopper transfers cut MSPT when your server is under real load.

More to configure

Per-world rules and toggles Paper never exposes — spawning, weather, mob behaviour — editable live, no restart required.

Built for plugin devs

Extra events and a cleaner item, enchant and scheduler API sit on top of the full Paper API — no relearning, just more to reach for.

Drop-in compatible

Same Paper API, same plugin ecosystem. Point your start script at the Origami jar and everything you already have keeps working.

Knobs Paper
doesn't give you.

A single origami.yml collects the extra tuning in one place, with sane defaults so an untouched server just runs.

origami.yml 
# tuning Paper leaves on the table
world-defaults:
  entity-tick-distance: 40        # tick mobs only near players
  merge-items-aggressively: true
  redstone-update-cache: true
  hopper:
    batch-transfers: true       # fewer partial moves/tick

chunks:
  async-generation: true

reload-without-restart: true

Fold it into your server.

Grab the latest build, drop it in, and start. Origami reads your existing Paper and Spigot configs untouched.
